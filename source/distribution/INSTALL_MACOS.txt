           Установка TapeXPlayer на macOS
════════════════════════════════════════════════════════════════

⚠️  ВАЖНО! Первый запуск:
═══════════════════════════════════════════════════════════════

1. НЕ запускайте двойным кликом!
2. Нажмите ПРАВОЙ кнопкой мыши на TapeXPlayer.app
3. Выберите "Открыть" (Open)
4. В появившемся диалоге нажмите "Открыть"

Готово! После первого запуска можно использовать обычный двойной клик.

───────────────────────────────────────────────────────────────

Альтернативный способ (через Терминал):
═══════════════════════════════════════════════════════════════

1. Откройте Терминал (Terminal.app)
2. Выполните команды:

   cd "Путь/к/папке/с/приложением"
   xattr -cr TapeXPlayer.app
   open TapeXPlayer.app

───────────────────────────────────────────────────────────────

Если появляется ошибка при запуске:
═══════════════════════════════════════════════════════════════

1. Попытайтесь открыть приложение
2. Откройте: Системные настройки → Защита и безопасность
3. В разделе "Основные" нажмите "Открыть в любом случае"

───────────────────────────────────────────────────────────────

Почему это происходит?
═══════════════════════════════════════════════════════════════

macOS проверяет все приложения из интернета через Gatekeeper.
Это нормальная мера безопасности.

Приложение полностью безопасно и функционально - просто оно
не прошло платную нотаризацию Apple ($99/год).
