# Управление клавишами TapeXPlayer 2026

## Основные команды воспроизведения

| Клавиша | Действие | Описание |
|---------|----------|----------|
| `SPACE` | Play/Pause | Переключение воспроизведения/паузы |
| `P` | Play | Запуск воспроизведения |
| `S` | Stop | Остановка воспроизведения |

## Управление скоростью

| Клавиша | Действие | Описание |
|---------|----------|----------|
| `+` или `=` | Увеличить скорость | Увеличивает скорость на 0.25x |
| `-` | Уменьшить скорость | Уменьшает скорость на 0.25x |
| `1` | Нормальная скорость | Устанавливает скорость 1.0x |
| `2` | Двойная скорость | Устанавливает скорость 2.0x |
| `0` | Половина скорости | Устанавливает скорость 0.5x |

**Диапазон скорости:** 0.25x - 4.0x

## Управление позицией

| Клавиша | Действие | Описание |
|---------|----------|----------|
| `←` | Назад 10 сек | Переход назад на 10 секунд |
| `Shift + ←` | Назад 1 мин | Переход назад на 1 минуту |
| `→` | Вперед 10 сек | Переход вперед на 10 секунд |
| `Shift + →` | Вперед 1 мин | Переход вперед на 1 минуту |
| `↑` | Вперед 1 мин | Переход вперед на 1 минуту |
| `↓` | Назад 1 мин | Переход назад на 1 минуту |
| `Home` | В начало | Переход в начало файла |
| `End` | В конец | Переход в конец файла |

## Управление громкостью

| Клавиша | Действие | Описание |
|---------|----------|----------|
| `9` | Уменьшить громкость | Уменьшает громкость на 10% |
| `0` | Увеличить громкость | Увеличивает громкость на 10% |
| `M` | Mute/Unmute | Переключение звука |

## Специальные функции

| Клавиша | Действие | Описание |
|---------|----------|----------|
| `R` | Reverse | Переключение обратного воспроизведения |
| `F` | Fullscreen | Переключение полноэкранного режима |
| `I` | Info | Показать информацию о файле |

## Системные команды

| Клавиша | Действие | Описание |
|---------|----------|----------|
| `Cmd + O` | Открыть файл | Открыть диалог выбора файла (macOS) |
| `Cmd + ,` | Настройки | Открыть окно настроек (macOS) |
| `Cmd + N` | Новое окно | Создать новое окно плеера |
| `Cmd + Q` | Выход | Завершить работу приложения (macOS) |
| `ESC` | Выход | Завершить работу приложения |

## Управление активным плеером

- Все команды управления применяются к **активному плееру**
- Активный плеер определяется через `GetActivePlayerID()`
- Можно переключаться между несколькими окнами плеера
- Каждое окно может иметь свой активный плеер

## Интеграция с OSD

- При выполнении команд обновляется OSD (On-Screen Display)
- OSD показывает текущее состояние плеера
- Визуальная обратная связь для всех действий

## Примеры использования

### Базовое воспроизведение
1. `Cmd + O` - открыть файл
2. `SPACE` - начать воспроизведение
3. `SPACE` - поставить на паузу
4. `S` - остановить

### Управление скоростью
1. `2` - установить 2x скорость
2. `+` - увеличить до 2.25x
3. `1` - вернуться к нормальной скорости

### Навигация по файлу
1. `→` - вперед на 10 секунд
2. `Shift + →` - вперед на 1 минуту
3. `Home` - в начало файла
4. `End` - в конец файла

### Обратное воспроизведение
1. `R` - включить обратное воспроизведение
2. `SPACE` - начать воспроизведение назад
3. `R` - выключить обратное воспроизведение

## Технические детали

- Все команды проверяют наличие активного плеера
- Команды возвращают коды ошибок при неудаче
- Скорость ограничена диапазоном 0.25x - 4.0x
- Позиция ограничена длительностью файла
- OSD обновляется автоматически при изменениях
